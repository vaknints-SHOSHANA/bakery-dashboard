# 🥐 דאשבורד מכירות מאפייה

דאשבורד שמציג נתוני מכירות של מאפייה עם 4 סניפים.
הנתונים **לא** מגיעים מקובץ סטטי. הם נמשכים בזמן אמת מבסיס נתונים ב-Airtable.

## איך הנתונים זורמים

```
Airtable (בסיס נתונים) → API + טוקן → pyairtable → pandas → Streamlit (דאשבורד)
```

## מה רואים בדאשבורד

- הכנסות, מספר הזמנות, פריטים שנמכרו והזמנה ממוצעת
- הכנסות לפי חודש, לפי סניף ולפי ערוץ מכירה
- 5 המוצרים המובילים
- סינון לפי סניף
- טבלה של שורות עם בעיות נתונים

## הוכחה שהנתונים חיים

שיניתי ב-Airtable את הסכום של הזמנה אחת מ-₪14 ל-₪100,000, ולחצתי על "Refresh data".
סך ההכנסות בדאשבורד עלה מ-₪647,095 ל-₪747,081, בלי לגעת בשום קובץ.
אחרי הבדיקה החזרתי את הערך המקורי.

## ניקוי הנתונים

הקובץ המקורי הגיע עם בעיות רבות, ותיקנתי אותן לפני ההעלאה ל-Airtable:
שמות סניפים, מוצרים וסטטוסים שנכתבו בכמה צורות, כמויות במילים, מחירים עם סימן ₪,
תאריכים בארבעה פורמטים שונים, ערכים חסרים ושורות כפולות.
שורות שלא ניתן היה לתקן סומנו בעמודה `data_issue`.
מ-29,142 שורות נשארו 29,127.

## איך מריצים

1. מתקינים את הספריות:
   ```
   pip install -r requirements.txt
   ```
2. יוצרים קובץ `.streamlit/secrets.toml` עם הפרטים מ-Airtable:
   ```toml
   AIRTABLE_TOKEN = "your_token_here"
   AIRTABLE_BASE_ID = "your_base_id_here"
   ```
3. מריצים:
   ```
   python -m streamlit run app.py
   ```

## אבטחה

הטוקן שמור בקובץ `secrets.toml`, שמופיע ב-`.gitignore`, ולכן לא עולה ל-GitHub.
לטוקן יש הרשאת קריאה בלבד, ורק לבסיס הזה.
